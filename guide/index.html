Cara Menggunakan Materi

Ikuti arahan untuk mempelajari CSS secara interaktif

1

Select Material

Pilih topik CSS dari menu Materi

2

Click Property Button

Klik property button untuk menampilkan penjelasan visualisasi

3

Edit The Code

Modifikasi kode HTML dan CSS secara langsung pada Live Editor

4

See Real-Time Preview

Live Preview akan menampilkan secara langsung kode yang kamu buat

Cara Menggunakan CSS Generator

Buat layout sederhana secara visual dan generate kodenya

1

Add Shapes

Buat persegi, lingkaran atau textbox yang dapat diedit

2

Drag & Resize

Drag atau Resize bentuk secara bebas di dalam canvas kerja

3

Generate Code

Klik Generate Code untuk menampilkan kode HTML dan CSS dari layout yang kamu buat

4

Copy The Result

Copy kode yang sudah generated dan bisa digunakan untuk proyek kamu

Learning Tips

Tingkatkan pengalaman pembelajaran CSS kamu

Cobalah memodifikasi kode secara langsung untuk memahami bagaimana properti CSS memengaruhi perilaku tata letak.
Gabungkan properti margin dan padding untuk membuat tata jarak (spacing) yang lebih rapi.
Gunakan CSS Generator untuk memahami positioning dan struktur tata letak secara visual.
